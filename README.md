Используемые технологии

Python 3

NumPy

SciPy

Cython

Установка зависимостей

Перед запуском необходимо установить используемые библиотеки:

pip install numpy scipy cython pyximport

Запуск заданий

Каждое задание находится в отдельном Python-файле.

Задание 1. Точность вычислений

python task_1.py

Демонстрируется разница между типами float32 и float64, машинный эпсилон и потеря точности при арифметических операциях.

Задание 2. Индексация и broadcasting

python task_2.py

Рассматриваются срезы массивов, выбор элементов по индексам, логическая индексация и выполнение операций с использованием broadcasting.

Задание 3. Memory-mapped файлы

Сначала необходимо создать файл с данными:

memory-mapped.py

Затем выполнить чтение и сравнение производительности:

task_3.py

Файл numpy_storage.dat создаётся автоматически при запуске memory-mapped.py. Он содержит массив размером 1000 × 1000 элементов типа float64.

Программа task_3.py открывает этот файл с помощью numpy.memmap, считывает отдельную строку и столбец, а также сравнивает скорость доступа к данным.

Задание 4. Разреженные матрицы

python task_4.py

Создаётся разреженная матрица формата CSR, выполняется её преобразование в COO и CSC, умножение на вектор и сравнение производительности разреженного и обычного массивов.

Задание 5. Использование Cython

python task_5.py

Сравнивается скорость вычисления суммы квадратов элементов на Python и Cython.

Файл helpme.pyx содержит реализацию функции на Cython. При первом запуске task_5.py модуль компилируется автоматически с помощью pyximport.

Примечание: для компиляции Cython в Windows может потребоваться установленный компилятор C/C++, например Microsoft C++ Build Tools.

Порядок выполнения

Установить Python и необходимые библиотеки.

Перейти в папку проекта.

Выполнить задания 1 и 2.

Запустить memory-mapped.py для создания файла данных.

Запустить task_3.py.

Выполнить task_4.py.

Запустить task_5.py для сравнения Python и Cython.

Результат

В результате выполнения лабораторной работы демонстрируются основные возможности NumPy, особенности работы с числовыми типами, индексацией и broadcasting, использование memory-mapped файлов, применение разреженных матриц SciPy и ускорение вычислений с помощью Cython.
